suricato

A small WebGL2 graphics library, ported to TypeScript from suricato.rs.

  • Hello world — a red quad
  • Textures — a textured quad
  • Instanced — a grid of spinning instanced quads
  • Camera, texture & lighting — a spinning textured cube
  • OBJ chair — a model loaded from an OBJ file
  • Uniform buffer objects — quads colored via UBOs
  • Draw line — a glTF fox wireframe with its skeleton
  • glTF — a model loaded from a GLB file
